Cấu Hình Google Cloud OAuth 2.0

Để ứng dụng có thể kết nối tài khoản Google Drive của bạn, bạn cần cung cấp một Google OAuth 2.0 Client ID (Web Application) được tạo miễn phí trên Google Cloud Console.

ID này chỉ lưu cục bộ trên trình duyệt của bạn (LocalStorage).

💡 Hướng dẫn tạo Client ID nhanh trong 2 phút:

  1. Truy cập Google Cloud Console và tạo một dự án mới (ví dụ: CleanDrive).
  2. Vào mục APIs & Services → Library, tìm và Enable "Google Drive API".
  3. Vào APIs & Services → OAuth consent screen, chọn User Type: External, điền tên ứng dụng và email.
  4. Vào APIs & Services → Credentials → Create Credentials → OAuth client ID.
  5. Chọn Application type: Web application.
  6. Tại mục Authorized JavaScript origins, thêm địa chỉ web đang chạy:
    http://localhost:3000 hoặc http://127.0.0.1:3000
  7. Sao chép Client ID vừa tạo và dán vào ô bên trên & bấm Lưu cấu hình.
